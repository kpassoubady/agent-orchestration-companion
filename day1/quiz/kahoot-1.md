# Kahoot Quiz 1: Planning and Model Selection

## Q1 (MCQ)

**Question:** What makes a development task agent-ready?

A. One observable deliverable with a verification path
B. Several related deliverables assigned to one agent
C. A flexible goal with agent-selected acceptance checks
D. A bounded file list without a named output

**Correct Answer:** A

**Rationale:** An agent-ready task has one observable deliverable and evidence that another person can verify.

## Q2 (MCQ)

**Question:** How should a plan handle a router shared by otherwise separate tasks?

A. Let every task update the router independently
B. Reserve the router for one integration owner
C. Duplicate the router in each task branch
D. Assign the router to the fastest channel agent

**Correct Answer:** B

**Rationale:** A structural hub needs explicit ownership, stable contracts, and an integration point.

## Q3 (MCQ)

**Question:** What should a useful dependency edge name?

A. The branch where upstream work was produced
B. An artifact or decision that unlocks downstream work
C. The preferred model for every downstream task
D. The planned start time for downstream work

**Correct Answer:** B

**Rationale:** Durable dependencies identify the artifact or decision required before downstream work begins.

## Q4 (MCQ)

**Question:** What does the task-card transfer test check?

A. Whether the task uses the fastest available model
B. Whether a new owner can act without hidden context
C. Whether all tasks can begin at the same time
D. Whether the task changes more than one file

**Correct Answer:** B

**Rationale:** A transferable card exposes the deliverable, files, dependencies, checks, and handoff evidence.

## Q5 (MCQ)

**Question:** Which action keeps the work-plan exercise within its assigned boundary?

A. Implement the notification renderers
B. Change the supplied validation rules
C. Complete the plan and preserve the validator
D. Rewrite the feature brief and repository map

**Correct Answer:** C

**Rationale:** Learners complete the planning artifact while preserving the supplied context, validator, and implementation boundary.

## Q6 (True/False)

**Question:** A stronger model replaces scoped permissions and human approval for high-risk work.

- True
- False

**Correct Answer:** False

**Rationale:** Model capability does not replace governance or risk controls.

## Q7 (MCQ)

**Question:** Which task signal most strongly calls for human approval?

A. A local copy edit that is easy to reverse
B. A specified mapping with focused tests
C. A high-blast-radius authorization change
D. A routine update with low verification cost

**Correct Answer:** C

**Rationale:** High-blast-radius work needs stronger controls regardless of model choice.

## Q8 (True/False)

**Question:** Model choice and effort are separate routing decisions.

- True
- False

**Correct Answer:** True

**Rationale:** The course treats model tier and response-token effort as separate levers.

## Q9 (MCQ)

**Question:** Which cost belongs in the cost of accepted work?

A. Model tokens and latency without review
B. Human review and regression repair
C. Model list price and advertised benchmark score
D. Implementation time without failed attempts

**Correct Answer:** B

**Rationale:** Accepted-work economics include attempts, latency, tokens, review, rework, and repair.

## Q10 (MCQ)

**Question:** What should stay fixed when comparing model configurations?

A. Task, prompt, tools, sandbox, time, and resource limits
B. Model, effort, and escalation threshold
C. Failure evidence and the next routing lever
D. Provider, model tier, and task boundary

**Correct Answer:** A

**Rationale:** Controlled conditions make outcome comparisons meaningful.

## Q11 (True/False)

**Question:** Repository outcomes are stronger grading evidence than an agent's completion message.

- True
- False

**Correct Answer:** True

**Rationale:** Tests and repository artifacts verify outcomes; completion claims do not.

## Q12 (MCQ)

**Question:** What justifies an evidence-based escalation?

A. A failed attempt with no recorded diagnostics
B. A reproducible failure or newly discovered risk
C. A slower response when every acceptance check passes
D. A preference change without new task evidence

**Correct Answer:** B

**Rationale:** Escalation requires new evidence and should change one relevant lever.
