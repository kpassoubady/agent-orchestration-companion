# Agent Orchestration Companion

Student companion repository for **Orchestration Fundamentals for Agentic
Development**.

This repository contains the hands-on materials for two independent breakout
labs. Learners practice creating a dependency-aware, agent-ready work plan and
coordinating parallel Claude Code sessions through isolated Git workspaces,
explicit file boundaries, structured handoffs, merge sequencing, and
acceptance checks.

## Prerequisites

Learners should be comfortable using Claude Code or a similar AI coding
assistant, working with Git branches and merges, and running commands in a
terminal.
