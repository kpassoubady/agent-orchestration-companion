# Agent Orchestration Companion

## Project Overview

Student-facing hands-on repository for **Orchestration Fundamentals for Agentic
Development**. It contains independent lab snapshots, feature briefs,
repository maps, task cards, model profiles, and acceptance checks used during
the four-hour course.

## Directory Layout

- `llm-context/`: Working context and notes for LLM agents.
- `scripts/`: Repository helper scripts.

## Verification Steps

Run every supplied acceptance check from both the starter and solution
materials after lab content is added.

## Content Guidelines

Keep each lab self-contained and independent of prior lab output. Give learners
bounded tasks, explicit file ownership, dependencies, acceptance criteria,
verification commands, handoff evidence, and human approval points.
